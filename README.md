# Tableau Portfolio

Hi, I'm Mohamed — this repo collects the Tableau projects I'm building while learning dashboard design, calculated fields, and data visualization. Each project folder has the workbook and a written breakdown of what I found.

## Projects

### Seattle Airbnb Pricing Analysis

Joined Seattle's Inside Airbnb listings and calendar data in Excel, engineered a Price per Bedroom field and a Peak/Off-Peak season flag, then built five views — price by bedroom count, listing count by bedroom count, and price by zip code — combined into an interactive Tableau dashboard tracking price trends across the year.

## Tools & Skills

- Tableau: dashboard design, calculated fields, filters
- Data prep: joins in Excel, feature engineering (season tagging, price-per-bedroom)
